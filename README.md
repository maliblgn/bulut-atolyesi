# Bulut Atölyesi

4 ana bölüm, 41 konu ve 299 alt kavramdan oluşan konu ağacıyla bulut bilişim sınav çalışma sitesi. 75 konu içi pekiştirme, 50 üretilmiş test, 30 kart, 112 test + 3 klasik çıkmış soru kaydı. Resmi cevap anahtarı yoktur; belirsiz sorular açıkça işaretlenir.

Bu depoda yalnız üretilmiş web sayfası dosyaları bulunur. Özgün ders PDF’leri, sınav fotoğrafları ve öğrenci bilgileri yayımlanmaz. Kaynak dosya adları ve konu kapsamı referans olarak gösterilir. İlerleme ve notlar yalnız tarayıcıda saklanır.
